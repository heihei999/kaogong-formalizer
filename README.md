# kaogong-formalizer

> 申论/面试口语→规范词自动转换工具。将日常口语化表述精准转换为公考官方规范用语。

## 为什么做这个

申论和面试中，考官看的是"官方语言"。但考生日常说的是口语，写出来的答案经常"太接地气"。比如：

- "村里没钱修路" → 要写成"资金紧张，基础设施薄弱"
- "坐等政府救济" → 要写成""等靠要"思想"
- "多个部门都管一件事" → 要写成"多头管理/政出多门"

这个工具帮你自动完成这个转换。

## 功能亮点

- 300+ 条口语→规范词映射，覆盖 11 个核心分类
- 7 个权威来源交叉验证（华图、中公、公考通、灵鹏教育等）
- 智能语境推断：对照表里没有的新表达也能转换
- 多候选输出：同一口语给出 2-3 个规范词，标注适用场景（申论概括/大作文/面试/公文）
- 段落级转换：一整段口语一次性转完，逐句标注替换点

## 快速开始

### 方式一：作为 Hermes Agent Skill

```bash
# 克隆到本地
git clone https://github.com/你的用户名/kaogong-formalizer.git

# 复制到 Hermes skills 目录
cp -r kaogong-formalizer ~/.hermes/skills/research/kaogong-formalizer
```

然后在对话中直接输入口语内容，Agent 会自动加载 skill 进行转换。

### 方式二：直接使用映射表

映射表文件在 `references/oral-to-formal-map.md`，是纯 Markdown 格式，可以直接查阅或集成到自己的工具中。

## 使用示例

**输入（口语）：**
> 现在村里年轻人都跑城里打工了，留下的都是老人小孩。村干部也没办法，只能等上面拨钱修路。有些领导就知道搞面子工程，花了不少钱但老百姓没得到什么好处。

**输出（规范）：**
> 当前农村人才外流严重，留守群体问题突出；基层治理能力有限，主要依赖上级财政转移支付。部分领导干部政绩观不正确，热衷面子工程，财政资金使用效率低，群众获得感不强。

**逐句对照：**

1. "年轻人都跑城里打工了" → 人才外流严重
2. "留下的都是老人小孩" → 留守群体问题突出
3. "村干部也没办法" → 基层治理能力有限
4. "只能等上面拨钱修路" → 主要依赖上级财政转移支付
5. "搞面子工程" → 政绩观不正确/热衷面子工程
6. "花了不少钱但老百姓没得到好处" → 财政资金使用效率低/群众获得感不强

## 测试结果

经过 60 条测试用例验证（基础题 30 条 + 歧义题 10 条 + 边界题 10 条 + 泛化题 10 条）：

## 转换规则

工具遵循 4 条核心规则：

1. **精确匹配优先**：对照表中有的直接命中
2. **语义扩展**：主体替换（老百姓→群众）、行为抽象（挨家挨户走→入户走访）、情感中立化（太差了→有待提升）、四字格优先
3. **多候选输出**：每个口语给 2-3 个规范词，标注适用场景
4. **语境敏感**：同一口语在不同语境下转换为不同规范词
